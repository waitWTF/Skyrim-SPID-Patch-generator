Skyrim SPID Patch Generator v0.4.12 - LANGUAGE SOURCE PREVIEW

Extract the complete folder. Start SkyrimSPIDPatchGenerator.exe, keeping Runtime and Documentation beside it.
Requires .NET 10 Desktop Runtime x64. In MO2, add the top-level EXE as a tool and launch through MO2.
Search an outfit, right-click Configure this outfit, then Save & close or Review & generate.
For invisible body parts, build/deploy the outfit meshes and rescan; see Documentation/README.md.
Existing WearableDistributor output filenames/settings are retained. Experimental outputs are separate.
Source: https://github.com/waitWTF/Skyrim-SPID-Patch-generator

Random outfit pools: Batch-check the outfits you want, open Configure checked, add NPC groups to one outfit, then use Random outfit pools in Distribution. Choose members, a shared overall chance and relative weights, Apply wardrobe, then Review & generate. Requires SPID 7.2+ for per-actor distribution. This does not schedule daily outfit changes.

For matching colors and normal/torn alternatives, open an existing setup and choose Balanced. Review & generate updates the installed patch; replacing the app alone does not rewrite it.

Interface language: select a language in Settings and wait for the animated app icon. It applies and saves automatically; no Save button or restart is needed. English, German, French, Spanish and Simplified Chinese are included.
This source preview has no new public binary ZIP while dependency/source-distribution review is pending. Build locally using README.md. See docs/RELEASE_VERIFICATION_0412.md for the translation/workflow checks and their limits.
