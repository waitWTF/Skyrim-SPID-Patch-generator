Skyrim SPID Patch Generator 0.4.4-preview

Extract the whole ZIP and keep all companion files together. Requires .NET 10 Desktop Runtime x64.
Run SkyrimSPIDPatchGenerator.exe. For MO2 launch through its executable list.
Settings -> Smart detect... finds game/MO2 locations and configured profile lists. Review paths and plugin visibility, especially if using a profile override.
Standalone detection does not expose MO2's virtual mods. Vortex users should deploy before scanning game Data.
For custom staging setups choose the Game Data override containing Skyrim.esm if required.
Choose a separate output mod folder yourself. Rescan and regenerate existing outfit entries to update recipients; untouched merged entries are retained.
The previous MO2 CET compatibility and uniformed NPC protection are retained. Merchandise requires SkyPatcher container support even with SPID NPC output.
